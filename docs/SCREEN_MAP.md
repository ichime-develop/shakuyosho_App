## 🔀 主な画面遷移（From → To）

```
ST0100        -> TO0100_PERSONAL

# TO0100（タブ）
/to0100/personal <-> /to0100/event  # タブ切替でURL同期

# 個人タブの導線
TO0100_PERSONAL -> FR0100           # 「すべて見る」
TO0100_PERSONAL -> FR0200           # 友だちカード
TO0100_PERSONAL -> LB0100           # 借用書発行
TO0100_PERSONAL -> TR0100           # 取引追加

# イベントタブの導線
TO0100_EVENT   -> EV0100            # すべて見る
TO0100_EVENT   -> EV0200            # イベントカード
TO0100_EVENT   -> EV0101            # イベント作成
TO0100_EVENT   -> SV0100            # 清算を計算
EV0100         -> EV0101            # 新しく作る

# フッター
ANY            -> FR0100            # ともだち
ANY            -> MY0100            # じぶん
ANY            -> TO0100_PERSONAL   # ホーム
```

---

## 🧭 命名・画面IDルール（抄）
- 2文字プレフィクス＋4桁番号：例 `TO0100`, `EV0200`
- 個人/イベントなどの **タブURL** は `/to0100/personal`, `/to0100/event` で固定
- ルーターは `lib/router/app_router.dart`、ホームは `To0100Screen(initialTab: X)`

---

## 🔧 更新手順（開発者向け）
1. ルート追加/変更時：`lib/router/app_router.dart` を修正
2. 画面を新設したら：本ファイルの表に **ID/名称/パス** を追記
3. 仕様変更：遷移図のブロックも更新

> Pull Request で必ずこのファイルの更新をレビュー対象に含めること。
